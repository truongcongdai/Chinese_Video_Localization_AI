# Hướng Dẫn Build và Release Windows Executable

## Tổng Quan

Hướng dẫn này mô tả quy trình build file .exe cho Chinese Video Localization AI và cách phân phối cho người dùng.

## Cấu Trúc Git Branch

```
main          - Branch ổn định cho production
develop       - Branch phát triển chính
windows_deploy_1 - Branch hiện tại cho Windows build
```

## Quy Trình Release

### Cách 1: Release Branch (Khuyên dùng cho production)

```bash
# 1. Checkout branch develop
git checkout develop
git pull origin develop

# 2. Tạo release branch
git checkout -b release/v1.0.0

# 3. Update version (nếu cần)
# - Sửa version trong file (nếu có file version)
# - Update CHANGELOG.md (nếu có)

# 4. Commit version bump
git add .
git commit -m "Bump version to v1.0.0"

# 5. Build .exe
.\build_exe.bat

# 6. Test .exe
cd dist\ChineseVideoLocalizationAI
.\run_app.bat

# 7. Nếu test thành công, merge sang main
git checkout main
git merge release/v1.0.0

# 8. Tag version
git tag -a v1.0.0 -m "Release v1.0.0"

# 9. Push main và tag
git push origin main
git push origin v1.0.0

# 10. Merge develop (để đồng bộ)
git checkout develop
git merge release/v1.0.0
git push origin develop

# 11. Xóa release branch
git branch -d release/v1.0.0
git push origin --delete release/v1.0.0
```

### Cách 2: Direct Release (Đơn giản hơn cho nhanh)

```bash
# 1. Checkout main
git checkout main

# 2. Merge develop

# 3. Update version (nếu cần)
```

## Chi Tiết Build Process

### Bước 1: Chuẩn bị

```bash
# Đảm bảo đang ở branch đúng
git checkout <branch_name>
git pull origin <branch_name>

# Kiểm tra file build configuration
# - build_exe.spec
# - scripts/run_web_wrapper.py
# - build_exe.bat
```

### Bước 2: Build Executable

```bash
# Chạy build script
.\build_exe.bat
```

**Quá trình build sẽ:**
1. Cài đặt PyInstaller (nếu chưa có)
2. Cài đặt dependencies từ requirements.txt
3. Build với PyInstaller sử dụng build_exe.spec
4. Copy file .env.example sang dist folder
5. Tạo file .exe trong thư mục dist/

**Thời gian build:** 10-30 phút tùy CPU

### Bước 3: Test Executable

```bash
cd dist\ChineseVideoLocalizationAI

# Cấu hình .env
.\setup_env.bat

# Chạy ứng dụng
.\run_app.bat
```

**Kiểm tra:**
- Server khởi động thành công
- Browser tự mở http://localhost:8080
- Web UI hiển thị đúng
- Login/đăng ký hoạt động
- License system hoạt động
- Tạo job test

### Bước 4: Đóng Gói Cho User

```bash
# Nén thư mục dist\ChineseVideoLocalizationAI\
# Đặt tên: ChineseVideoLocalizationAI-v1.0.0-Windows.zip
```

**Cấu trúc thư mục phân phối:**
```
ChineseVideoLocalizationAI-v1.0.0-Windows.zip
└── ChineseVideoLocalizationAI/
    ├── ChineseVideoLocalizationAI.exe    (File thực thi - ~2.9GB)
    ├── .env                             (File cấu hình)
    ├── local_data/                      (Dữ liệu local)
    │   ├── database.sqlite3
    │   ├── temp/
    │   ├── output/
    │   └── logs/
    ├── temp/                            (Thư mục tạm)
    ├── setup_env.bat                    (Script cấu hình)
    ├── run_app.bat                      (Script chạy app)
    ├── run_direct.bat                   (Script chạy trực tiếp)
    └── README.txt                       (Hướng dẫn sử dụng)
```

## Hướng Dẫn Cho Người Dùng

### Cài Đặt

1. **Giải nén file zip** vào thư mục bất kỳ
2. **Chạy setup_env.bat** để tạo file cấu hình
3. **Chạy run_app.bat** để khởi động ứng dụng

### Cấu Hình

File `.env` chứa các cấu hình quan trọng:

```env
# Web Server
WEB_PORT=8080
WEB_SESSION_SECRET=<auto-generated>

# Credits
JOB_COST_CREDITS=0  # 0 = unlimited

# Registration
OPEN_REGISTRATION=true  # Cho phép user tự đăng ký

# AI Models
SPEECH_MODEL=base  # tiny, base, small, medium, large
IMAGE_AI_MODEL=stabilityai/sd-turbo

# License Server (Centralized License Management)
LICENSE_SERVER_URL=  # Để trống để dùng database local
# LICENSE_SERVER_URL=http://your-license-server.com  # Để dùng license server centralized
```

### Sử Dụng

- **Trang web:** http://localhost:8080
- **Admin UI:** Đăng nhập với user đầu tiên (tự động là admin)
- **License Management:** Trong trang admin, tạo license cho user
- **Free Trial:** User có thể dùng trial miễn phí (10 tokens, 7 ngày)

## License Server (Centralized License Management)

### Tổng Quan

License Server là hệ thống quản lý license centralized cho phép bạn:
- Quản lý license từ một server duy nhất
- Theo dõi usage (jobs, tokens) theo thời gian thực
- Revoke license khi cần
- Bind license vào máy cụ thể

### Yêu Cầu Server

- **CPU:** 1 core minimum
- **RAM:** 512MB minimum
- **OS:** Ubuntu 20.04+ (hoặc bất kỳ Linux)
- **Python:** 3.8+
- **Disk:** 100MB minimum

### Deploy License Server

#### Bước 1: Upload Files

```bash
scp license_server/server.py root@your-server:/opt/license-server/
scp license_server/static/admin.html root@your-server:/opt/license-server/static/
scp license_server/deploy_ubuntu.sh root@your-server:/opt/license-server/
```

#### Bước 2: Deploy

```bash
ssh root@your-server
cd /opt/license-server
chmod +x deploy_ubuntu.sh
./deploy_ubuntu.sh
```

#### Bước 3: Configure Domain

```bash
nano /etc/nginx/sites-available/license-server
# Update server_name to your domain
nginx -t
systemctl restart nginx
```

#### Bước 4: Enable HTTPS (Khuyên dùng)

```bash
certbot --nginx -d your-domain.com
```

#### Bước 5: Access Admin Panel

Truy cập: `http://your-domain.com/static/admin.html`

### Cấu Hình Client

Để sử dụng license server với ứng dụng:

1. Set `LICENSE_SERVER_URL` trong file `.env`:
   ```env
   LICENSE_SERVER_URL=http://your-license-server.com
   ```

2. Để trống để dùng database local (backward compatibility):
   ```env
   LICENSE_SERVER_URL=
   ```

### Quản Lý License

#### Tạo License

1. Truy cập admin panel: `http://your-domain.com/static/admin.html`
2. Điền thông tin:
   - Customer Name
   - Customer Email
   - Plan Type (basic, pro, enterprise)
   - Features
   - Expiry Days (để trống cho lifetime)
   - Max Jobs
   - Max Tokens
   - Machine ID (optional - để bind vào máy cụ thể)
3. Click "Create License"
4. Copy license key và gửi cho user

#### Validate License

Khi user nhập license key, ứng dụng sẽ tự động:
- Gọi API để validate license
- Check usage limits
- Update usage statistics

#### Revoke License

1. Truy cập admin panel
2. Tìm license muốn revoke
3. Click "Edit"
4. Change status thành "revoked"
5. Save

## Troubleshooting

### Lỗi Build

**Lỗi: "No module named 'xxx'"**
- Thêm module vào hiddenimports trong build_exe.spec
- Rebuild lại

**Lỗi: "Could not import module"**
- Kiểm tra pathex trong build_exe.spec
- Đảm bảo src/universal_video_ai được thêm vào path

**Lỗi: "Library not found"**
- Thường là warning, có thể bỏ qua
- Nếu gây lỗi, cần thêm DLL vào binaries

### Lỗi Runtime

**Lỗi: "WEB_SESSION_SECRET is not set"**
- Chạy setup_env.bat
- Hoặc thêm thủ công vào .env

**Lỗi: "Port already in use"**
- Đổi WEB_PORT trong .env
- Hoặc kill process đang dùng port 8080

**Lỗi: "ModuleNotFoundError"**
- Rebuild với hidden imports đã thêm
- Kiểm tra spec file
